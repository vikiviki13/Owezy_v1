Design System · v1.0

Owezy

You Pay, We Remember.

Mobile-first expense sharing PWA for tracking money lent to and borrowed from friends. This file is the single source of truth for all colors, type, spacing, radii, elevation, icons and components used across every Owezy screen. All values are extracted directly from the production application code (src/index.css theme tokens + component styles).

Platform · Mobile PWA (390–448pt) Typeface · Inter Grid · 4pt base Themes · Light + Dark Icons · Lucide, stroke 2

Screens using this system

Onboarding Auth Home Friends Friend Detail Groups Activity Add Expense Expense Detail Record Repayment Contact Import Spending Overview Profile & Settings Statement / Export Security · PIN Lock

How to read this document: every token is shown as Token path + raw value. Every component shows its Variant → State → Specimen → Dimensions. Component specimens are rendered at real mobile size inside 358px frames (= 390pt screen minus 16pt page padding on each side).

Amount Display Rules

· Always tabular numerals (amount-tabular) for alignment.

· Symbol precedes value without space: ₹450 (long codes get a space: AED 100).

· Repayments render with a “+” prefix in Success green; expenses stay Text Primary.

· Indian grouping by default (1,23,456.78) per user preference.

Motion

· Bottom sheet entrance: slide-up 220ms cubic-bezier(0.32, 0.72, 0, 1).

· Tab swipes: 200ms translateX ±32 with fade from 0.3 opacity.

· Switch thumb: 200ms ease-out translate.

· prefers-reduced-motion collapses all animation to instant.

Touch & Accessibility

· Minimum touch target 40×40; rows and buttons reach 44–56.

· Visible focus ring everywhere: 3px primary @45%, offset 2.

· Safe-area insets respected top and bottom (notch / home indicator).

· Privacy cover obscures balances when the app loses focus.
